# 🌹 Rose Plant Monitoring and Crop Yield Prediction

An AI-powered smart agriculture project that uses **Deep Learning and Computer Vision** to monitor rose plants, detect flowers, estimate crop yield, and classify leaf diseases.

## 📌 Overview

This project combines **YOLOv8** for rose detection and counting with **EfficientNet** for rose leaf disease classification. The system is designed to work with real-world agricultural images containing challenges such as complex backgrounds, overlapping flowers, varying lighting conditions, and different disease patterns.

The project involved collecting and preparing a real-world rose detection dataset, preprocessing images, applying data augmentation, experimenting with multiple deep learning models, and evaluating their performance.

## 🚀 Features

* 🌹 Rose flower detection using YOLOv8
* 🔢 Automatic rose counting for crop yield estimation
* 🍃 Rose leaf disease classification
* 🧠 Experimentation with multiple deep learning models
* 📊 Model training and performance evaluation
* 🖼️ Image preprocessing and data augmentation
* 🌱 Smart agriculture and plant health monitoring

## 🧠 Disease Classes

The classification system identifies the following categories:

* Black Spot
* Downy Mildew
* Fresh Leaf
* Insect Hole
* Powdery Mildew
* Rose Mosaic
* Rose Rust
